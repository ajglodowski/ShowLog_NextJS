Titles sit on the art

How a wash is made

Start from the poster's average color (fetchAverageShowColor already exists). Convert to OKLCH, clamp lightness to 0.30–0.36 and chroma to 0.09 or below, and keep the hue.

Show pages fade from the wash to graphite by 90% of the first screen. On Discover, the wash appears only inside the highlighted row, fading left to right.

Orange rules

  • Your status, as text and icon
  • The primary button: one per screen
  • The active tab and nav underline, 2px
  • Never as a background tint, glow, or wash
  • Never for ratings. Ratings are chalk and stone.

Type

Geist, one family, no second face and no mono. Weight and tracking do all the work. On iOS, SF Pro takes the same sizes and weights.

The rule

  • Solid chalk, always. Never filled with the poster.
  • Overlaps the image by about 40% of its line height
  • A black 0→55% scrim on the lower half of the image
  • Long names wrap to two lines, then scale down. Never truncate a show title.
  • No text shadows, no glow, no outline

Surfaces

Four surfaces, all built from the same glass. Depth comes from blur and the lit top edge, never from colored shadows.

GlassWhite 6% · blur 26 · saturate 140% · 1px line · 1px lit top edge at 13%. Panels, cards, nav.
Deep glassGraphite 50%, same edge. For anything over busy imagery: tab bar, buttons on posters.
WellBlack 24% inside glass. Search fields, text inputs.
Highlighted rowGlass plus its show's wash, left to right. Hover, focus, and keyboard selection.

Radius

20 panels and sheets · 16 cards · 12 rows, inputs, segments · 999 chips and tab bar. Posters take 9–20 based on size.

Spacing

4 icon to label · 8 row padding, chip gap · 12 panel padding · 16 between blocks · 24 between sections. Rows have no dividers.

Shadow

Only under poster cards: 0 24 40 −16 black 60%. Nothing else casts a shadow.

Rules

  • Official SVG on the official color, like the app icon
  • The tile always comes before the name
  • Never recolor, outline, or tint a mark
  • Never place a mark on orange or on a wash

Sources

The marks and hex values shown are from Simple Icons (CC0 artwork; the trademarks belong to their owners). Hulu and Prime Video come from its archive, because the owners asked for removal from the current set.

For production, take each mark from the service's own press kit. The two naming mismatches to fix: the data says HBO (the product is HBO Max) and Amazon (the product is Prime Video).

Build it

The guide maps onto what's already in both repos: shadcn tokens in globals.css, .glassEffect in SwiftUI, and the existing service table.

/* replaces the current dark :root values */
:root {
  --background: #0C0B0A;   /* graphite */
  --foreground: #F5F1EC;   /* chalk */
  --muted-foreground: #A39B93;
  --primary: #F2A13A;
  --primary-foreground: #231300;
  --border: rgb(255 255 255 / 8%);

}

iOS · Theme.swift

enum Theme {
  static let graphite = Color(hex: 0x0C0B0A)
  static let chalk    = Color(hex: 0xF5F1EC)
  static let stone    = Color(hex: 0xA39B93)
  static let orange   = Color(hex: 0xF2A13A)
}

extension View {
  // glass container
  func showlogGlass(_ r: CGFloat = 20) -> some View {
    glassEffect(in: .rect(cornerRadius: r))
  }
}

// hero title over the poster
Text(show.name)
  .font(.system(size: 50, weight: .black))
  .tracking(-3)
  .padding(.top, -44)

Wash · shared rule

// same math in TS and Swift; store the result
// on the show row so both apps read one value
function wash(avg: Oklch): Oklch {
  return {
    l: clamp(avg.l, 0.30, 0.36),
    c: Math.min(avg.c, 0.09),
    h: avg.h,
  };
}
